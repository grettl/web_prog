# Лабораторные работы по веб-программированию

## Лабораторная работа №1 — Магазин посуды

Интернет-магазин на HTML, CSS и JavaScript без фреймворков.

Возможности:
- просмотр каталога товаров;
- добавление товаров в корзину;
- изменение количества и удаление товаров;
- выбор товаров для заказа;
- оформление заказа с проверкой полей формы.

[Открыть магазин](https://grettl.github.io/web_prog/lab1/)

[Исходный код](https://github.com/grettl/web_prog/tree/main/lab1)

## Лабораторная работа №2 — Список задач

Планер на чистом JavaScript. Интерфейс создаётся через DOM API.

Возможности:
- добавление, редактирование и удаление задач;
- выбор срока выполнения и цвета задачи;
- отметка выполнения;
- поиск по названию;
- фильтрация по статусу;
- сортировка по дате;
- изменение порядка перетаскиванием мышью или пальцем;
- сохранение задач в localStorage;
- счётчик активных и выполненных задач;
- отмена последнего удаления;
- адаптивное оформление для компьютера и телефона.

Для перетаскивания нужно выбрать «Без сортировки».
На телефоне перенос выполняется за кнопку ↕.

Задачи хранятся отдельно в каждом браузере.

[Открыть планер](https://grettl.github.io/web_prog/lab2/)

[Исходный код](https://github.com/grettl/web_prog/tree/main/lab2)
